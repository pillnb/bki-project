# Digitalisasi Proses Bisnis BKI Komersil Balikpapan
Proyek ini bertujuan untuk mendigitalisasi dan mengotomatisasi beberapa proses bisnis di BKI Komersil Balikpapan untuk meningkatkan efisiensi dan produktivitas.

### Deskripsi
Sistem ini dirancang untuk mempermudah pengelolaan data dan dokumen internal. Dengan adanya digitalisasi, proses yang sebelumnya manual kini menjadi lebih cepat, terpusat, dan mudah diakses oleh pegawai yang berwenang.

### Fitur Utama
Proyek ini memiliki empat fitur utama:

* Dashboard Pegawai: Menampilkan ringkasan informasi dan metrik penting bagi pegawai. Memudahkan pemantauan kinerja dan akses cepat ke fitur lainnya.

* CV Generator: Memungkinkan pegawai untuk membuat atau memperbarui Curriculum Vitae (CV) secara otomatis berdasarkan data yang sudah ada di sistem.

* Surat Tugas: Mengotomatiskan proses pembuatan dan pengarsipan surat tugas. Pegawai dapat mengajukan permintaan dan atasan dapat memberikan persetujuan secara digital.

* Training Management: Fitur untuk mengelola jadwal, materi, dan daftar peserta untuk kegiatan training atau pelatihan internal.

### Teknologi yang Digunakan
* Frontend: React.js
* Backend: Typescript
* Database: PostgreSQL
